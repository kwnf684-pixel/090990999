# نظام الصيرفة والحوالات

واجهة عربية RTL تجريبية مبنية بـ React وTypeScript وVite. جميع البيانات محلية ثابتة؛ لا توجد قاعدة بيانات أو API أو مصادقة أو تكاملات خارجية أو منطق مالي. الخط مضمن محليًا. يخزن المتصفح تفضيل الثيم فقط.

## التشغيل

```sh
npm install
npm run dev
npm run build
npm run lint
```

تبدأ الواجهة من `/dashboard`. تعريف جميع الوحدات والمسارات في `src/data/navigation.ts` والبيانات التجريبية في `src/data/mockData.ts`. المكونات المشتركة في `src/components`، والـDashboard في `src/pages/Dashboard.tsx`، وتجميع مسارات واجهة المكتب في `src/app/App.tsx`. يمكن إضافة تطبيق إدارة المالك مستقلًا مستقبلًا دون إدخاله في واجهة المكتب الحالية.

البحث العام شكلي. الإجراءات السريعة تفتح صفحات الوحدات قيد التطوير ولا تنفذ عمليات. تاريخ Dashboard ثابت ضمن البيانات الاستعراضية. عند الاستضافة مستقبلًا، يلزم توجيه مسارات SPA إلى index.html.
